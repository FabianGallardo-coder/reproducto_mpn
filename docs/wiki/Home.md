# Documentación de FlowPlayer

FlowPlayer es una aplicación de escritorio para música local, YouTube y radio. Estas guías describen el comportamiento del código actual; no son una certificación de todas las plataformas o servicios externos.

## Empezar

- [Primeros pasos](Primeros-pasos.md): preparar el entorno y abrir música.
- [Biblioteca y playlists](Biblioteca-y-playlists.md): organizar y buscar archivos.
- [YouTube y radio](YouTube-y-radio.md): video, descargas y emisoras.
- [Modos y atajos](Modos-y-atajos.md): elegir una vista y controlar con el teclado.

## Administrar y resolver problemas

- [Configuración y datos](Configuracion-y-datos.md): preferencias, historial y respaldos.
- [Solución de problemas](Solucion-de-problemas.md): diagnosticar audio, archivos e integraciones.

## Desarrollar y publicar

- [Desarrollo](Desarrollo.md): arquitectura, IPC, iconos y compilación.
- [QA](QA.md): pruebas de interfaz y escritorio real.
- [Publicación](Publicacion.md): publicar esta Wiki y el sitio de presentación.

El código fuente vive en [FabianGallardo-coder/reproducto_mpn](https://github.com/FabianGallardo-coder/reproducto_mpn). Las copias Markdown de estas páginas se mantienen en el repositorio para poder revisarlas junto con los cambios de código.
