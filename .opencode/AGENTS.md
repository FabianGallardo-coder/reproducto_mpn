# AGENTS

Write lean, concise code. Before writing anything, walk through this decision ladder:

1. Can standard libraries or native platform features handle this?
2. Does an existing dependency or piece of code in the project do this already?
3. Can this be reduced to a one-liner?

Stop AI agents from over-engineering solutions and writing bloated code. Delete fifty lines of complex code and replace them with one when possible. Never cut validation, error handling, security, or accessibility.
